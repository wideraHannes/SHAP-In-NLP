## Advantages and Challenges of SHAP

**TL;DR:** SHAP is a theoretically well-founded and flexible explanation method that works across many NLP models and tasks, but it can be computationally expensive, especially for long texts and Transformer-based models. Its explanations should also be interpreted carefully because SHAP values are not causal explanations and can be misunderstood.

### 6.1 Advantages
One of the biggest advantages of SHAP is its theoretical basis in game theory, which allows us to generate highly valuable explanations that fulfill the properties of additive feature attribution methods discussed in Section 3.1.3. As discussed in Section 2.1.1, the primary purpose of explanation techniques is to help humans understand the reasoning behind a model's output. SHAP achieves this goal primarily by producing contrastive explanations. It provides a clear and intuitive understanding of each feature's contribution to the model's output by visualizing the effect of each token on the prediction.
Moreover, SHAP offers a high degree of expressiveness by providing a wide range of plots and allowing customization of plots to suit the evaluator's specific needs. Additionally, the Partition Explainer is an efficient method for approximating SHAP values without being limited by the exponential runtime of the exact computation.
The use of faster estimation methods allows SHAP to calculate multiple explanations efficiently, providing a comprehensive global explanation of the model's functioning. As demonstrated in Chapter 5, SHAP demonstrates remarkable portability, as it can be applied to various NLP tasks and works with different machine learning models. By only perturbing the input features and observing the changes in the output, SHAP is able to treat every model as a black box. This flexibility minimizes extra overhead when switching between tasks and models, making SHAP model- and task-agnostic and facilitating fast and straightforward explanations.
As demonstrated in this thesis, SHAP's versatility and effectiveness make it a valuable tool for interpreting NLP models. Additionally, many SHAP-based techniques for NLP have evolved from the original framework, either extending it or creating new model- or task-specific explanations [50]. SHAP is also a foundation for many recently proposed explanation techniques [52, 57, 58]. Furthermore, the Python library `shap` is open source, and at the time of writing this thesis, the repository exhibits a substantial number of contributions and active development, which is a positive indication for the future of SHAP.

### 6.2 Challenges and Considerations

The main challenge of using SHAP is the resource-intensive computation of SHAP values. Although computational complexity was reduced by the introduction of the Partition Explainer, long texts and complex models such as Transformers still cause problems for fast computation of SHAP values. We experienced this issue in particular when calculating SHAP values for the sentiment analysis task using the BERT model.
While the computation for one prediction by BERT is already slower than that of simpler models, it becomes even more expensive when calculating SHAP values for a sample. In this case, we need to compute BERT's output for many coalitions. Even if the total number of coalitions is reduced by the Partition Explainer, the computation can still be costly. This problem becomes even more severe as the input length increases.
We observed that this issue is negligible when generating an explanation for a single sample. However, if time is limited and a global explanation is required, this can become a serious limitation.
Another important aspect to consider is that SHAP values cannot be used for causal inference. Instead, they reveal how each feature affects a model's prediction without directly showing its effect on the target variable. It is crucial to keep in mind that a model may not always precisely represent real-world phenomena. Therefore, SHAP values do not provide direct insight into causation [59, 60].
This leads to another concern: evaluators might misinterpret explanations and draw incorrect conclusions. This can result from confirmation bias or even malicious intent, making it a disadvantage for recipients of the explanations, as they cannot be entirely certain of the accuracy of the explanation [12, 60].
Additionally, there are criticisms that existing SHAP-based methods overlook uncertainties in explanations, cause unexpected changes in Shapley values, and attribute positive impacts to features that do not significantly affect the machine learning model [61]. Furthermore, it is essential to note that SHAP might not always accurately capture certain model behaviors due to its low translucency, as it lacks insight into the model's weights. In such cases, additional model-specific explanation techniques with higher translucency may be needed to complement SHAP explanations.
